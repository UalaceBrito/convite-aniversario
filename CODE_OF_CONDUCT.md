# Código de Conduta

## Nosso compromisso

Nos comprometemos a tornar a participação neste projeto uma experiência livre
de assédio para todos, independentemente de idade, corpo, deficiência, etnia,
identidade de gênero, nível de experiência, nacionalidade, aparência, raça,
religião ou identidade sexual.

## Padrões

Exemplos de comportamento positivo:

- Uso de linguagem acolhedora e inclusiva
- Respeito por diferentes pontos de vista
- Feedback construtivo

Exemplos de comportamento inaceitável:

- Linguagem ou imagens sexualizadas
- Comentários ofensivos, ataques pessoais
- Assédio público ou privado

## Aplicação

Casos podem ser reportados para `aniversario@exemplo.com`.
