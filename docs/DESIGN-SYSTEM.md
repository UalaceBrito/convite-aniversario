# Design System

## Tokens

Definidos em `src/css/base/_tokens.css`:

- **Cores**: `--bg`, `--surface`, `--text`, `--gold`, `--pink`
- **Tipografia**: `--font-display` (Playfair), `--font-body` (Inter)
- **Espaçamento**: `--gutter`, `--section-y`
- **Raios**: `--r-sm`, `--r-md`, `--r-lg`, `--r-pill`
- **Sombras**: `--shadow-sm`, `--shadow-md`, `--shadow-lg`, `--shadow-glow`
- **Movimento**: `--ease`, `--t-fast`, `--t`, `--t-slow`

## Princípios

1. Mobile-first
2. Acessibilidade por padrão
3. Performance como feature
4. Sem dependências CSS externas
5. Design tokens como única fonte de verdade
